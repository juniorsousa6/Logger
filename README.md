# Logger

App de Mac para descarregar cartões de memória: cria a pasta do trabalho (`AAAA_MM_DD - evento`), reconhece cada cartão, copia para a pasta certa, confere tudo por checksum e só então diz que pode formatar. Nada no cartão é apagado ou alterado.

**Instalar:** baixe o pacote mais recente em `dist/`, descompacte e dê duplo clique em `Instalar Logger.command`. Veja `LEIA-ME.md`.

O app se atualiza sozinho a partir deste repositório (`latest.json`).
